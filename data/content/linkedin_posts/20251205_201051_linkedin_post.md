Your LLM API bills are about to get 30-60% cheaper.

I just discovered TOON (Token-Oriented Object Notation), and it's solving a problem most of us didn't realize was costing us thousands: JSON is bleeding tokens.

Every bracket, comma, and repeated key in your JSON payloads gets tokenized and billed. When you're sending arrays of objects to GPT-4 or Claude, you're paying for the same keys hundreds of times.

TOON flips this:

→ Declares object keys once in tabular arrays
→ Strips redundant syntax while staying lossless
→ Maintains full bidirectional JSON compatibility
→ Reduces tokens by 30-60% on typical payloads

The math is compelling:

Processing 1M log entries monthly?
• JSON: 150M tokens = $2,250
• TOON: 60M tokens = $900
• Savings: $1,350/month

Here's the production pattern:

1. Keep JSON in your application code (tooling, libraries, familiarity)
2. Convert to TOON at the LLM API boundary (where tokens = money)
3. Let the LLM process cleaner, more structured data
4. Convert responses back to JSON if needed

Bonus: Many engineers report improved LLM accuracy because the tabular format makes patterns more obvious to models.

TOON isn't replacing JSON everywhere—it's a specialized optimization layer for the one place it matters most: your LLM bill.

Libraries available for TypeScript, JavaScript, and Python. VS Code extension. CLI tools. It's production-ready now.
