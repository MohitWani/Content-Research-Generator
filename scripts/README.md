# Scripts

This folder contains utility and management scripts. 

✅ Common Use Cases for scripts/ Folder
`Script Type`	        `Description`
Setup scripts	        Set up environments, databases, configs
Data scripts	        Load, clean, or transform data
Run scripts	            Entry-point to trigger application or training
Deployment scripts	    Build, deploy, or publish the project
Maintenance	            Cleanup tasks, backups, monitoring
Debug tools	            Print logs, inspect database states


# Setup pre-commit hook for formatting and linting.

```
chmod +x ./scripts/setup-hooks.sh

./scripts/setup-hooks.sh 
```
